# wangge-ai

### AI 实战开源组织｜Skills、工具与可复用工作流

`wangge-ai` 是旺哥发起的开源组织，不是个人主页。这里集中维护已经完成公开审查、适合安装和协作的 Skill 与工具。

想了解旺哥本人、文章和实践经历，请进入 **[wangge-dev 个人主页](https://github.com/wangge-dev)**。

## 核心开源项目

| 项目 | 用途 | 当前状态 |
|---|---|---|
| [wangge-skills](https://github.com/wangge-ai/wangge-skills) | 电商、数据分析、GitHub、前端设计与 RPA 等 Agent Skills 的安装和维护入口 | 公开维护，首批 7 个 Skill |

新项目只有在功能、依赖、许可证、隐私和安全检查完成后才会进入这里。尚在开发或包含业务资料的仓库保持私有。

## 开源原则

- 来源与许可证清楚，第三方内容保留归属说明。
- Skill 使用标准 `SKILL.md` 结构，说明依赖、能力和边界。
- 示例尽量使用脱敏或模拟数据，不公开账号、Cookie、密钥和业务隐私。
- 成熟项目独立成库，轻量工作流由 `wangge-skills` 统一索引。

安全报告、贡献方式和发布检查以各项目仓库中的 `SECURITY.md`、`CONTRIBUTING.md` 和发布文档为准。
